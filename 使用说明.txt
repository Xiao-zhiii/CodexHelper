 Codex 小帮手  使用说明（Node.js + Codex CLI 一键安装 · 插件修复）
═══════════════════════════════════════════════════════

【这是什么】
一个完全独立的绿色单文件程序（Codex小帮手.exe，约 41 MB），
内部已打包 Node.js v24.18.0 离线安装包，把它拷贝到任何 Win10 / Win11
电脑上都可以直接双击运行，不需要提前安装 Python、Node.js 或其他任何环境。

【使用方法】
1. 把 Codex小帮手.exe 复制到目标电脑（U盘/网络传输均可）。
2. 建议【右键 → 以管理员身份运行】：
   程序启动时会提示是否使用管理员模式，普通双击运行时也可在弹窗里
   一键选择“以管理员身份重新启动”（若取消授权则以普通权限继续，
   安装 Node.js 时会单独弹出授权窗口）。
3. 若 Windows SmartScreen 弹出蓝色提示框：
   点【更多信息】→【仍要运行】（因为 exe 没有购买数字签名，属正常现象）。
4. 程序会自动检测当前环境（Node.js / npm / Codex CLI 的版本）。
5. 点击【一键安装 Node.js 和 Codex CLI】：
   - 安装 Node.js 时会弹出“用户账户控制(UAC)”授权窗口，请点【是】；
     之后为静默安装，约 1~3 分钟，装到 C:\Program Files\nodejs\。
   - 安装 Codex CLI 前，程序会自动执行
     Set-ExecutionPolicy RemoteSigned 解除 PowerShell“禁止运行脚本”限制，
     避免之后运行 codex 命令时被拦截（管理员时设 LocalMachine，
     否则设 CurrentUser；若被组策略接管则按组策略为准并提示）。
   - Codex CLI 通过 npm 全局安装（@openai/codex）：
     优先使用 npmmirror 国内镜像；超过 5 分钟未完成会自动切换 npm 官方源重试。
6. 安装完成后，打开【新的】PowerShell 或 CMD 窗口，输入 codex 即可使用。

【Codex 插件一键修复】（v1.2.0 新增）
适用场景：Codex 桌面端升级后，Chrome 插件 / 浏览器插件 /
Computer Use（电脑操作）插件无法使用、按钮变灰或功能消失。
点击界面上的【🛠 一键修复 Codex 插件】，程序会自动完成：
1. 检测本机是否已安装修复技能 codex-windows-fast-patch-skill，
   没有则自动从 GitHub 下载安装（多个下载源自动切换）；
2. 把 Codex 权限自动设置为 Full Access
   （写入 ~/.codex/config.toml，原配置自动备份为
   config.toml.nodecodexsetup.bak）；
3. 写入 /goal 自定义指令（~/.codex/prompts/goal.md），
   之后你在 codex 里随时输入 /goal 也能调取修复技能；
4. 自动打开一个新的 PowerShell 窗口运行 Codex CLI（Full Access 模式），
   自动确认“目录信任”提示，并自动【逐字符键入】修复指令（等效人工打字）
   开始排查修复。
注意：
· 需要先安装好 Codex CLI（可用本工具先安装）；
· 请不要在 Codex 窗口里按 Ctrl+V——新版 codex 把 Ctrl+V 绑定为
  “粘贴剪贴板图片”，文字会粘贴不进去（报 no image on clipboard）；
· 若自动键入未成功（个别环境会被安全策略拦截），程序会弹窗提醒：
  修复提示词已复制到剪贴板 —— 点击刚打开的 Codex（PowerShell）窗口，
  【鼠标右键】即可粘贴，然后按回车开始修复；
· 修复过程由 Codex 自主执行，请在其窗口内确认与观察。

【ChatGPT 启动修复】（v1.4.0 新增分页）
适用场景：打开 ChatGPT 桌面应用报错：
    ChatGPT failed to start. Unable to locate the Codex CLI binary.
    Set CODEX_CLI_PATH or ensure the Electron resources include bin/codex.
切换到【ChatGPT 启动修复】分页，程序会自动检测：
· ChatGPT 桌面应用（OpenAI.Codex）是否安装、版本与位置；
· 应用内的 codex.exe CLI 是否存在；
· CODEX_CLI_PATH 环境变量是否已设置。
点击【🔧 一键修复 ChatGPT 启动报错】，程序自动：
1. 定位应用内的 codex.exe（找不到时回退用 npm 版 Codex 的原生程序）；
2. 写入用户环境变量 CODEX_CLI_PATH（仅当前用户，无需重启电脑）；
3. 自动重启 ChatGPT 应用使修复生效。

【Codex CLI 首次使用】
需要配置 OpenAI API Key（在新的终端窗口执行，setx 永久生效）：
    setx OPENAI_API_KEY "sk-你的key"
然后重新打开终端，运行：
    codex

【常见问题】
· 双击没反应 / 被杀毒软件拦截：退出杀软或添加信任后重试。
· PowerShell 提示“禁止运行脚本”：本工具安装 Codex 前会自动执行
  Set-ExecutionPolicy RemoteSigned 解除限制；若个别电脑仍报错，
  以管理员身份打开 PowerShell 手动执行一次即可。
· Node.js 安装时 UAC 被点了“否”：程序会提示，重新点安装再点是即可。
· Codex 安装失败：多为网络问题，检查代理/防火墙后重试；
  本工具会自动在镜像源和官方源之间切换。
· 想重新检测环境：点界面上的【重新检测】按钮。
· 安装 Node.js 建议重启电脑一次以使 PATH 完全生效（一般不重启也能用）。

【文件清单】（本目录）
· Codex小帮手.exe   —— 成品，单文件直接分发
· node-v24.18.0-x64.msi     —— Node.js 离线安装包（已打包进 exe，留作备用源：
                               放在 exe 同目录可被优先识别）
· src\                      —— Python 源码与图标，便于日后修改重新打包
   - node_codex_installer.py    主程序（tkinter GUI）
   - make_icon.py               图标生成脚本
   - installer.ico              程序图标
   - NodeCodexSetup.spec        PyInstaller 打包配置
   - dist\NodeCodexSetup.exe    打包原始输出

【重新打包方法】（修改 src\node_codex_installer.py 后）
  pip install pyinstaller
  python -m PyInstaller --onefile --windowed --name NodeCodexSetup \
      --icon installer.ico \
      --add-data "node-v24.18.0-x64.msi;assets" \
      --add-data "installer.ico;assets" \
      node_codex_installer.py
